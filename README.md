# С НУЛЯ: Симулятор жизни

Русскоязычная офлайн-игра для Android-браузера: герой начинает без денег, жилья и документов — и сам выбирает путь: карьера, учёба, своё дело, друзья и семья или свободная жизнь.
HTML5 / CSS3 / JavaScript, без движков, фреймворков и CDN. Версия 0.2.0, формат сохранения v2.

## Быстрый старт
| Как | Что открыть |
|---|---|
| Просто поиграть на телефоне без интернета | `dist/s-nulya-offline.html` — один файл, всё внутри |
| Разработка на компьютере | `python3 -m http.server 8080` в папке проекта → http://localhost:8080 |
| Установить как приложение (PWA) | разместить папку на HTTPS-хостинге (см. ниже) |

## Как запустить на Android
**Вариант А — один файл, без интернета.**
1. Скопируйте `dist/s-nulya-offline.html` на телефон (USB, мессенджер «себе», облако с офлайн-доступом).
2. Откройте файл в Chrome: в «Файлах» → нажать на файл → «Открыть с помощью» → Chrome. Если Chrome не предлагается, введите в адресной строке `file:///sdcard/Download/s-nulya-offline.html`.
3. Прогресс сохраняется в браузере. Перед очисткой данных Chrome сделайте «Ещё → Настройки → Экспорт».

**Вариант Б — локальный сервер в Termux** (полная версия с PWA на localhost):
`pkg install python` → перейти в папку игры → `python -m http.server 8080` → открыть `http://localhost:8080` в Chrome → меню ⋮ → «Установить приложение».

## Как разместить PWA на HTTPS-хостинге
Service Worker работает только по HTTPS или на localhost (не из `file://`). Подойдёт любой статический хостинг:
- **GitHub Pages:** создать репозиторий → загрузить содержимое папки (с `index.html` в корне) → Settings → Pages → Branch `main`, папка `/root` → через минуту игра доступна по `https://<логин>.github.io/<репозиторий>/`.
- **Netlify / Cloudflare Pages:** перетащить папку в веб-интерфейс («Deploy manually»), сборка не нужна.
- Пути относительные (`./`), поэтому игра работает и в подпапке.

На телефоне откройте адрес в Chrome → ⋮ → «Установить приложение» / «Добавить на главный экран». После первого запуска все ресурсы в кэше — игра работает без сети.
**Обновление:** после изменения файлов поменяйте `CACHE` в `sw.js` (например `s-nulya-0.2.1`), иначе телефоны останутся на старой версии.

## Структура проекта
```
index.html               точка входа (CSP, manifest, порядок модулей)
manifest.webmanifest     PWA-манифест;  sw.js — офлайн-кэш
css/style.css            дизайн-система: токены, компоненты, 44px касания, отключаемые анимации
assets/                  фото сцены Старого района, иконки 192/512/maskable
js/core/                 util (ГПСЧ, шина событий) · state (создание, миграции, нормализация) · clock (время, календарь, погода, переход дня) · save
js/data/                 декларативные данные: мир, работа, учёба, жильё/вещи, бизнес, услуги, NPC+диалоги, события, задания/достижения
js/systems/              логика без DOM: stats, economy (+город, документы, универсальные действия), work (+образование), property, business, finance, social, events, quests (+рыбалка, быстрые действия)
js/ui/                   scene (SVG-сцена и аватар) · components · screens · sheets (диалоги, события, мини-игра)
js/main.js               маршрутизация, делегирование кликов, автосохранение, регистрация SW
tests/                   engine.test.js (Node) · ui_test.py (headless Chrome 360×780)
tools/build.js           сборка однофайловой версии в dist/
docs/                    ANALYSIS (анализ прототипа) · ECONOMY (формулы и баланс) · MODES (правила режимов)
```
Системы общаются с интерфейсом только через события (`SN.emit('toast' | 'modal' | 'newday' …)`), поэтому ядро тестируется без браузера.

## Отчёт по этапу
### Готово и работает
- **Ядро:** время по действиям, календарь с 1 октября, сезоны, погода, детерминированный переход дня; 9 показателей с объяснимыми последствиями; обморок → бесплатная больница вместо проигрыша.
- **Работа:** 13 подработок (лимиты в день) и 12 вакансий с собеседованием (мини-диалог из 2 вопросов), будничными сменами, зарплатой на карту, 5 ступенями карьеры, прогулами и увольнением.
- **Образование:** 16 курсов (бесплатные, платные, школа, колледж, вузы, автошкола) с реальными требованиями; самообразование растит навык до потолка, но документов не даёт.
- **Город:** 7 районов с ценами, интерактивная карта, 6 видов транспорта с автовыбором; бесплатные службы соццентра (обед, душ, стирка, вещи, медпункт, ночлежка).
- **Жильё и имущество:** хостел, комната, квартира (аренда + залог + выселение), студия и дом (покупка, коммуналка, продажа 85%); 11 вещей с перепродажей и обслуживанием; 6 комплектов одежды (тепло + внешний вид).
- **Документы:** паспорт (через соцработника), ОМС, медкнижка, права, ИП — со сроками готовности.
- **Бизнес:** 6 видов, персонал, цены, реклама, расширение, работа владельца, продажа; полная модель прибыли/убытка с налогом 6%, сезонами и долгами.
- **Финансы:** счёт и карта, вклад, кредит с лимитом и просрочкой, 2 инвестиционных инструмента с предупреждениями, история операций, график доходов/расходов, чистый капитал.
- **Люди:** 8 NPC с биографиями, целями, расписаниями, памятью поступков и 35 вариантами в диалогах; личные сюжетные арки (Серёга и дочь, Михалыч и сын, альбом Лёши, мастерская Валеры, стартап Коли, наставничество Марии, мастерские Нины Петровны); дружба, телефон, совместные занятия, романтика по согласию → пара → совместная жизнь → свадьба.
- **События:** 19 случайных с выбором и 3 сезонных; 34 задания в 8 линиях; 24 достижения; уровни опыта; мини-игра «Рыбалка».
- **Персонаж:** имя, тон кожи, волосы, борода, одежда видны в сцене; сцена меняется по времени суток, погоде, району.
- **Сохранения:** автосохранение, контрольная сумма, резервная копия, экспорт/импорт JSON, перенос сохранения прототипа, защита от подделанных файлов.
- **PWA:** manifest, иконки, service worker (cache-first), однофайловая офлайн-сборка; CSP, экранирование, никакой сети и аналитики.
- **Доступность:** касания ≥ 44 px, без горизонтального скролла на 360 px, safe-area, крупный текст, отключение анимаций, `prefers-reduced-motion`, aria-атрибуты.

### Проверено
- Сценарии ТЗ автотестами: работа → доход → еда → отдых; обучение → доступ к профессии; аренда, выселение, покупка и продажа жилья; бизнес → ежедневная прибыль/расходы и простой без персонала; дружба → согласие на свидание; диалог → направление на паспорт → документ через 5 дней; сохранение → перезагрузка → восстановление.
- Баланс симуляцией ботов на 30–40 дней и расчётом окупаемости бизнесов.
- В Chrome на 360×780: все экраны, шторки, собеседование, рыбалка, финансы, бизнес; однофайловая версия из `file://`.
