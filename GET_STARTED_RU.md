# Начало работы с NOVA OS 0.12

1. Этот ZIP — **исходники**, а не образ: на флешку его не записывайте.
2. Получите ISO: `BUILD_RU.md` (GitHub Actions с телефона или Debian 13).
3. Проверьте ISO: SHA-256, сводку `verify-iso.sh` и скриншоты загрузочного теста в артефактах запуска.
4. Проверьте ноутбук в Live-режиме с флешки, не трогая Windows: `nova-docs/USB_LIVE_TEST_RU.md`.
5. Внутри NOVA: «NOVA — самопроверка системы», «NOVA — персонализация», NOVA Control.

Устанавливать рядом с Windows 11 — только после резервной копии и проверки сценария в VM (план 0.13).
