# NOVA OS 0.12 — System Experience & ISO Readiness

NOVA OS — экспериментальный дистрибутив на базе **Debian 13 (trixie) + KDE Plasma 6 (Wayland)** с русским интерфейсом и собственными инструментами: NOVA Control, Defender, Task Manager, Driver Center, Update & Recovery, Android/Phone Hub, Gaming, Sound Studio, перенос данных из Windows и др.

ISO собирается в GitHub Actions (вкладка Actions → Artifacts) или на Debian 13. Версия 0.12 — первая, чей ISO реально собран и загружен в виртуальной машине в режимах BIOS и UEFI. На реальном ноутбуке и установка на диск ещё не проверены.

## Быстрый старт

- **Дисплеи и клавиши:** `nova-docs/DISPLAY_KEYS_RU.md`.
- **С телефона:** `BUILD_RU.md` → «Только телефон + GitHub». Результат: ISO, скриншоты загрузки BIOS/UEFI и отчёты.
- **Проверка на ноутбуке без риска для Windows 11:** `nova-docs/USB_LIVE_TEST_RU.md` (Ventoy/Rufus, BitLocker, Fast Startup, Live-режим).
- **Проверка исходников:** `bash tools/validate-project.sh` (без root и сети).

## NEON//SYS — встроенное киберпанк-оформление (готовится к 0.13)

Второе оформление рядом с NOVA Air, собранное только из того, что уже есть в образе: HUD-панель и плавающий док,
**живые QML-обои Plasma** (Synth Grid, Night City, Data Rain, Circuit — без Wallpaper Engine/Lively, пауза на
батарее), стандартные виджеты Plasma, режимы WORK/GAME/NIGHT/FOCUS, неоновая тема всех окон NOVA, профиль Konsole,
звуковая тема и заставка загрузки. Включается в первом запуске, в Персонализации или по **Win+Alt+N**; прежний вид
возвращается одной кнопкой. Подробно: `nova-docs/NEON_RU.md`.

## Что нового в 0.12

- **Сборка ISO:** исправлен несуществующий пакет (`spectacle` → `kde-spectacle`), добавлен офлайн-пул GRUB для Calamares (BIOS и UEFI), единый файл `VERSION`, проверка свободного места, манифест пакетов, полноценный `verify-iso.sh`.
- **Автотесты в CI:** загрузка ISO в QEMU/KVM (BIOS и UEFI) до рабочего стола Plasma, самопроверка внутри VM через гостевой агент, скриншоты Plasma в 1366×768 / Full HD / 2K / 4K@200 %; скриншоты всех 18 окон NOVA на тех же экранах в светлой и тёмной теме.
- **NOVA Air для Plasma:** светлый и тёмный Look-and-Feel пакеты, цветовые схемы, шрифт Inter, SDDM и экран блокировки с обоями NOVA, раскладки EN/RU (Alt+Shift).
- **Режимы рабочего стола:** Windows-like (панель снизу, приложения по центру), Dock-like (верхняя строка + док), Hybrid (плавающая панель); резервная копия перед каждой сменой и «Вернуть KDE Plasma по умолчанию». Приложение **NOVA — персонализация** и CLI `nova-layout`.
- **Единый UI-набор `nova_ui`:** общие цвета (контраст ≥ 4.5:1), окна вписываются в экран 1366×768 и HiDPI, адаптивная навигация, одинаковые диалоги подтверждения, индикатор выполнения, фокус для клавиатуры, Ctrl+Q/Ctrl+F.
- **Дисплеи:** частота обновления (Гц), второй монитор как Win+P, профили мониторов, откат через 15 с, яркость внешнего монитора (DDC/CI), экономия батареи снижением частоты.
- **Клавиатура как в Windows:** Win+↑/↓, Win+Tab, Win+Shift+S, Win+Пробел, Ctrl+Shift+Esc, Win+I, Win+R, Win+G; громкость с шагом 2 %, клавиши калькулятора/почты/браузера, проверка клавиш. **NOVA Game Bar** по Win+G. Значки Papirus.
- **`nova-selftest`:** проверка сеанса, экранов и масштаба, GPU (включая гибридную NVIDIA), сети, звука, ввода, брандмауэра, AppArmor, установщика.
- **Безопасность по умолчанию:** брандмауэр UFW включён (входящие запрещены).
- Исправлены падения NOVA Control и Task Manager, белые вкладки в тёмной теме, окна выше экрана.

Подробно: `CHANGELOG_RU.md`, `nova-docs/AUDIT_0.12_RU.md`.

## Ограничения (без ложных обещаний)

- Не все Windows-программы работают через Wine/Bottles; современный Microsoft Office, античиты и драйверные утилиты — через Windows в виртуальной машине или веб-версии.
- Google Play/GMS не входят в ISO; Android-приложения — через Waydroid по запросу, Gmail — в браузере.
- Проприетарный драйвер NVIDIA не ставится автоматически; после установки — через NOVA Driver Center (Secure Boot потребует регистрации ключа MOK).
- Не устанавливайте NOVA на диск с Windows без резервной копии; сценарий dual boot будет проверяться в VM в 0.13.

## Структура

- `image/config/` — конфигурация live-build: списки пакетов, хуки, оверлей (`includes.chroot`).
- `image/config/includes.chroot/usr/local/bin/` — приложения NOVA (PyQt6) и их ядра; `nova_ui.py` — общий UI-набор.
- `tools/` — сборка (`build-iso.sh`), проверка ISO, QEMU-тесты, генераторы темы и брендинга.
- `tests/` — регрессионные тесты 0.3–0.12.
- `design/mockups/` — **концепт-макеты**, а не скриншоты работающей системы.
- `nova-docs/` — документация модулей, аудит, матрица тестов, инструкция USB.
