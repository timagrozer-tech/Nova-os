# NOVA Phone Hub — USB, Wi-Fi и Samsung

1. **USB-экран.** Подключите Android телефоном по USB (данные, а не только зарядка). На телефоне включите «Для разработчиков → Отладка USB». Авторизуйте ключ ADB на экране. В `NOVA Phone Hub` нажмите «Найти устройства», выберите статус `device` и «Показать экран». Требуется установленный scrcpy.
2. **Wi-Fi экран.** В одной доверенной Wi-Fi сети включите на Android «Беспроводная отладка», выберите сопряжение кодом, введите IP:порт и шестизначный код в NOVA. Затем укажите адрес подключения/порт, а не порт сопряжения, и нажмите «Подключить». Есть также опциональное переключение USB → TCP/IP по официальной процедуре scrcpy. Не включайте ADB на недоверенной сети.
3. **KDE Connect.** Установите KDE Connect на сам телефон из Play Store/F-Droid. Через локальную Wi-Fi сеть подтвердите сопряжение на обоих устройствах; доступны файлы, уведомления, общий буфер обмена, дистанционная мультимедиа и ввод. Bluetooth для этой части не обязателен.
4. **Samsung DeX.** Фирменный DeX for PC ориентирован на Windows и прекращён на One UI 7+. В Linux нет официального эквивалента. NOVA предоставляет зеркалирование `scrcpy` и экспериментальный виртуальный Android-дисплей (`--new-display=1920x1080`), который НЕ запускает гарантированно настоящий Samsung DeX и может не показывать рабочий стол без лаунчера.
5. **Установка scrcpy.** В окне Phone Hub нажмите «Установить scrcpy» — после согласия привилегированный помощник подключит Debian 13 Backports и установит пакет `scrcpy` из `contrib`. Пакет Debian может при первом запуске загрузить `scrcpy-server` с оригинального источника.
6. **Конфиденциальность.** NOVA не получает Google-пароли. ADB-коды сопряжения скрываются в форме и передаются процессу через stdin. По завершении нажмите «Отключить Wi-Fi ADB»; также выключите «Беспроводную отладку» на телефоне.

## Новое в 0.6: качество и запись

Выберите пресет качества в NOVA Phone Hub. Указанные разрешение и FPS — верхние
пределы, реальные параметры зависят от телефона, Wi-Fi и кодека.
Запись MP4/MKV начинается **только** при установке галочки и выборе нового
файла. Перезапись уже существующего файла на момент запуска запрещена.
Запись может содержать персональные данные, экран банковских приложений
может быть скрыт Android по соображениям безопасности.
