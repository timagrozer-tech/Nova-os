# NOVA Migration — что переносится из Windows в NOVA OS

## После установки NOVA OS рядом с Windows

1. Загрузитесь **именно в установленную NOVA OS**, а не в Live-режим флешки. В Live пользовательские файлы могут храниться в RAM и исчезнуть при перезагрузке — мастер блокирует импорт в Live.
2. Откройте файловый менеджер **Dolphin**. Выберите доступный раздел Windows, при необходимости смонтируйте его средствами рабочего стола. Доступ к зашифрованному BitLocker-разделу возможен только после штатной разблокировки; программа **не** расшифровывает диск и не запрашивает ключи.
3. Откройте **NOVA Migration**. Нажмите **Выбрать папку пользователя Windows** и найдите `.../Users/ИмяПользователя`.
4. Отметьте нужные категории. Если хотите импортировать игры или проект вне папки Windows-профиля — **Дополнительная папка**. Для каждого Windows-пользователя выполните импорт отдельно.
5. Подтвердите перенос. Копии сохраняются в новой приватной папке `~/NOVA-Импорт/NOVA-Имя-.../`. В Windows ничего не удаляется и не переименовывается.
6. Прочитайте `ОТЧЁТ-О-ПЕРЕНОСЕ.json` (успехи, ошибки и пропуски) и сравните важные файлы с оригиналами прежде, чем решать удалить резервную копию.

## Категории

- Документы, рабочий стол, загрузки, фото, видео, музыка, избранное Windows.
- Сохранения игр из `Saved Games` и `Documents/My Games` (не все игры хранят сохранения здесь).
- Темы/фоновые изображения из `AppData/Roaming/Microsoft/Windows/Themes`.
- Дополнительный пользовательский каталог (по явному выбору).
- Закладки Chrome, Edge и Firefox — экспорт в импортируемые HTML-файлы; закладки **не** добавляются автоматически в профиль текущего браузера.
- Перечень программ Windows — `Программы_Windows_каталог.csv` на основе ярлыков меню «Пуск» и, если есть, `winget-apps.json` из Windows. Это **не перенос бинарников и не переустановка программ**.

## Как экспортировать перечень приложений из Windows заранее

Скопируйте/запустите `tools/windows/NOVA-Windows-Export.ps1` в Windows под своей учётной записью. Он создаёт `Рабочий стол/NOVA-Export/winget-apps.json` (если доступен winget) и текстовый отчёт с диагностикой. Скрипт не изменяет разметку, BitLocker и загрузчик. Иногда winget не перечисляет вручную установленные программы; дополнительно NOVA сканирует ярлыки.

Можно использовать `winget export -o "%USERPROFILE%\\Desktop\\NOVA-Export\\winget-apps.json"` отдельно (папка должна существовать).

## Windows-программы и Office

- Нативные Linux-версии устанавливаются заново из Linux-репозиториев / Flatpak.
- Поддерживаемые Windows-программы устанавливаются заново с помощью Wine/Bottles; просто скопированный каталог `Program Files` обычно не работает.
- Некоторые **portable** EXE запускаются напрямую через Wine (индивидуальная совместимость).
- Программы с драйверами Windows, античитом, Microsoft 365 Desktop и сложным лицензированием часто требуют Windows или Windows VM.
- Для Office откройте Microsoft 365 в браузере или загрузитесь в сохранённую Windows 11.

## Что намеренно не переносится автоматически

Сохранённые пароли, cookies, секреты, токены, зашифрованные профили браузеров, реестр Windows, драйверы, службу Windows Update, сертификаты и лицензионные ключи. Эти элементы нельзя автоматически конвертировать в безопасную настройку Linux. Папки OneDrive только в облаке нужно предварительно скачать на диск Windows; иначе данные отсутствуют в файловом разделе.

**Ограничения:** выборочный перенос — копирование файлов и отчёт. Не заявляется миграция всех настроек Windows или полностью готовых установленных программ. Проверка на реальном NTFS/BitLocker пока не выполнена.
