# NOVA Performance Center · v0.8

Технологическая основа: Debian 13 `power-profiles-daemon`, Python `psutil`, `GameMode`, `MangoHud`, KDE Plasma System Monitor.

**Никакого скрытого «FPS Boost»**: профили доступны лишь если их предоставляет ОС. На многих ноутбуках профиля `performance` нет; вместо принудительного обхода это отображается как отсутствие поддержки.

## Безопасные действия

- CPU/RAM/батарея/температуры — только чтение Linux API. Если драйвер не предоставил датчик, показывается «Недоступно».
- Установка предупреждения по температуре — только косметическое, без управления вентилятором и без обещания защиты от перегрева.
- Понижение приоритета — только для процессов текущего пользователя, с проверкой времени рождения PID для защиты от его переиспользования; не убивает процесс, не повышает привилегий.
- Питание — через штатную команду `powerprofilesctl`, а не прямую запись в `/sys`. Высокая производительность требует подтверждения.
- GameMode применяется к конкретным играм: `gamemoderun %command%` в Steam. Совместимость с античитами, драйверами и играми не гарантирована.

## Оговорки

- Частоты, энергопрофили и датчики зависят от ноутбука; GPU NVIDIA требует проприетарный драйвер и рабочую утилиту `nvidia-smi`.
- Порог предупреждения: 65–105 °C, задаётся пользователем; это не универсальный безопасный предел температуры.
- Не заменяет аппаратные аварийные механизмы охлаждения или штатный Windows/UEFI контроль.
- 0.8 всё ещё исходники, не проверенный ISO.
