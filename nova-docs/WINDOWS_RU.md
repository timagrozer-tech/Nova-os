# Окна NOVA: рамки Fluent и Aqua, анимации

NOVA рисует рамки окон сама — две темы KWin Aurorae, созданные с нуля (без чужих картинок и логотипов),
в шести цветовых вариантах, чтобы заголовок сливался с панелью инструментов приложения.

| | NOVA Fluent (язык Windows 11) | NOVA Aqua (язык macOS) |
|---|---|---|
| Кнопки | свернуть / развернуть / закрыть справа, 46×32, тонкие значки; «закрыть» краснеет при наведении | три цветные кнопки слева, значки появляются при наведении, у неактивного окна — серые |
| Заголовок | слева, со значком приложения, высота 32 | по центру, высота 30 |
| Углы и тень | 8 px, тонкая рамка 1 px, мягкая тень | 12 px, более крупная и мягкая тень |
| Сворачивание | «сжатие» к панели задач | «волшебная лампа» в док |
| Скорость анимаций | быстрая (×0,75) | плавная (×0,9) |
| Активный угол | нет | верхний левый — обзор окон |

Стили: NOVA Air, Ocean, Aurora, Horizon, NEON — Fluent; Sakura — Aqua. Horizon меняет и цвета, и рамку
(светлая/тёмная) по солнцу. Размытие с лёгким «зерном» (как акрил Windows 11), поиск KRunner появляется
по центру экрана (как поиск Windows и Spotlight). «Вернуть как было» возвращает и прежние рамки, и анимации.

Окна приложений NOVA плавно проявляются при открытии (≈ 250 мс), а разделы и вкладки при переключении
проявляются и чуть поднимаются (≈ 170 мс, замедляющаяся кривая — как в Windows 11). Скорость следует
настройке Plasma; функция «Уменьшить движение» отключает анимации полностью.

Проверки: `tests/test_v15_chrome.py`; тест загрузки в QEMU снимает каждый стиль с открытым Dolphin.
