# Звуковые темы и события NOVA OS

1. Откройте NOVA Sound Studio → импортируйте собственные WAV/OGG/MP3/FLAC/M4A/OPUS.
2. Выберите события, сохраните назначения звуков, затем нажмите «Экспортировать тему звуков».
3. NOVA создаст **новую**, уникальную папку в `~/.local/share/sounds/NOVA-Personal-*`
   с `index.theme` и `.oga`/`.disabled`, не меняя ни один системный файл.
4. Откройте настройки KDE: «Параметры системы → Звук» или
   «Уведомления → Настроить → Настроить события».
5. Назначьте экспортированную тему там, где KDE/приложение её поддерживает.

**Ограничения:** экспорт темы и обработка UPower — разные механизмы.
KDE-приложения могут использовать собственные звуки из `.notifyrc`,
а сторонние приложения — собственные библиотеки. Универсального программного
переключателя, заменяющего все звуки всех программ, в Linux нет.

**Конфиденциальность:** все звуковые файлы остаются локально. Экспорт не запускает
root-команды, не читает чужие файлы и не загружает данные в облако.
Используется FFmpeg только для конвертации в Ogg Vorbis, длина до 12 сек.
