# NEON//SYS — встроенное киберпанк-оформление NOVA OS

NEON//SYS — второе оформление NOVA наряду с NOVA Air. Оно собрано **только из того, что уже есть в образе**:
пакет оформления Plasma, цветовая схема, QML-плагин живых обоев, стандартные виджеты Plasma, профиль Konsole,
звуковая тема и приложения NOVA. Ничего не скачивается, root не нужен, системные файлы не меняются.
NOVA Air остаётся оформлением по умолчанию для новых пользователей.

## Как включить

- **Первый запуск** → «Внешний вид» → «NEON//SYS — киберпанк».
- **NOVA — персонализация** → «Тема оформления» → «NEON//SYS — киберпанк» (только цвета, звуки и обои, панель не меняется)
  или кнопка «NEON//SYS: живые обои, виджеты, режимы…».
- **NOVA Control** → «Оформление и панель» → «Центр NEON//SYS».
- **Win+Alt+N** — центр NEON//SYS (`nova-neon-center`).
- Терминал: `nova-neon apply` (полностью) или `nova-neon apply --look-only` (без смены панели).

Вернуть прежний вид — кнопка «Вернуть прежнее оформление» или `nova-neon revert`: возвращаются прежняя
тема (NOVA Air светлая/тёмная или KDE), раскладка панелей из резервной копии, обои, звуки, профиль терминала,
экран блокировки, а также питание, «Не беспокоить» и ночной режим, если их менял режим NEON.

## Что входит

| Часть | Как сделано | Где лежит |
|---|---|---|
| Цвета Plasma и окон | цветовая схема `NovaNeon` из тех же токенов, что и приложения NOVA (контраст ≥ 4.5:1) | `/usr/share/color-schemes/NovaNeon.colors` |
| Глобальная тема | Look-and-Feel `org.nova.neon.desktop`: схема, значки Papirus-Dark, Breeze-рамки, заставка загрузки NEON | `/usr/share/plasma/look-and-feel/org.nova.neon.desktop` |
| Рабочий стол | тонкая HUD-панель сверху (меню, рабочие столы, часы, трей) + плавающий док снизу | скрипт `nova_neon_core.plasma_script` |
| Живые обои | QML-плагин Plasma: Synth Grid, Night City, Data Rain, Circuit, «по времени суток» | `/usr/share/plasma/wallpapers/org.nova.neon.wallpaper` |
| Виджеты | монитор NEON Stats (процессор, память, сеть из /proc, свой виджет NOVA) и стандартные: часы, календарь, музыка, заметки (список дел), таймер (помидор) | только из `plasma-workspace` и `plasma-widgets-addons` |
| Приложения NOVA | тема `neon` в `nova_ui` (все 22 окна) | `/usr/share/nova/themes/neon.qss` |
| Терминал | профиль Konsole `NEON` и схема `NovaNeon` | `/usr/share/konsole` |
| Звуки | тема `nova-neon` (19 событий freedesktop, Ogg Vorbis) | `/usr/share/sounds/nova-neon` |
| Шрифты | Orbitron и Share Tech Mono (SIL OFL 1.1, лицензии рядом) — только латинские заголовки и цифры | `/usr/share/fonts/truetype/nova-neon` |
| Экран блокировки | статичная картинка Synth Grid | `/usr/share/wallpapers/NOVA-NEON` |

## Живые обои

Обои написаны на QML и рисуются самой Plasma — без Wallpaper Engine, Lively или браузерного движка.

- Один таймер на всю сцену (по умолчанию 30 кадров/с, настраивается 5–60), статичные слои рисуются один раз.
- **Энергосбережение:** при работе от батареи анимация замирает (через встроенный источник данных Plasma
  `powermanagement`; если он недоступен, обои просто не ставятся на паузу).
- Режим **GAME** ставит анимацию на паузу.
- Правый щелчок по рабочему столу → «NEON//SYS: следующие обои» / «пауза анимации». **Win+Alt+W** — следующие обои.
- Настройки: правый щелчок → «Настроить рабочий стол и обои» → «NEON//SYS — живые обои» (сцена, кадры, скорость,
  пауза на батарее, часы на обоях).

## Режимы

| Режим | Клавиши | Что делает |
|---|---|---|
| WORK | Ctrl+Win+Alt+1 | возвращает ваши питание, уведомления и ночной режим; обои по времени суток |
| GAME | Ctrl+Win+Alt+2 | профиль питания «производительность», «Не беспокоить», обои на паузе |
| NIGHT | Ctrl+Win+Alt+3 | обои Night City, ночной режим экрана |
| FOCUS | Ctrl+Win+Alt+4 | обои Data Rain, «Не беспокоить» |

Перед первым переключением из WORK NEON запоминает ваши исходные значения (`~/.config/nova/neon.json`) и
возвращает именно их — режим WORK не включает уведомления, если вы их выключали сами.

Сочетания NEON не пересекаются ни с KDE, ни с таблицей «как в Windows» NOVA (проверяется тестом). Пока NEON
выключен, клавиши режимов ничего не меняют и только показывают подсказку.

## Безопасность и откат

- Всё — на уровне пользователя: `kwriteconfig6`, `plasma-apply-lookandfeel`, скрипты Plasma через D-Bus.
  Нет `sudo`, `pkexec`, сети и `shell=True` (проверяется тестом).
- Перед сменой панелей — резервная копия раскладки в `~/.local/share/nova/layout-backups/` (как у `nova-layout`).
- Виджеты NEON помечаются и при повторном включении заменяются; ваши собственные виджеты не трогаются.
- На узких экранах виджеты не ставятся, на маленьких — ставятся только те, что помещаются.

## Проверка

- `bash tools/validate-project.sh` — тесты `tests/test_v13_neon.py`: скрипты Plasma выполняются в Node с
  макетом API (Full HD, 1366×768, вертикальный экран, отсутствующие виджеты), CLI в режиме `--dry-run`,
  все сгенерированные файлы, сочетания клавиш, отсутствие загрузок.
- GitHub Actions (`ui-smoke`): все окна NOVA в теме `neon` на четырёх разрешениях и отрисовка каждой сцены
  живых обоев и заставки загрузки в PyQt6 (`tools/neon_qml_smoke.py`, скриншоты в артефакте).
- **Не проверено:** работа в живой сессии Plasma 6 на реальном ноутбуке (виджеты, «Не беспокоить», ночной режим,
  заставка загрузки). Это пункт для первой проверки в VM/на ноутбуке.
