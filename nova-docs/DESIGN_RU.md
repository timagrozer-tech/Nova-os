# NOVA Air — дизайн и адаптивность

## Стиль

Новые макеты утверждены как концепции. Палитра — серо-белая подложка, светло-голубые акценты, мягкие границы, неяркие прозрачности. Вдохновение: организация рабочего пространства Windows 11 + аккуратность macOS. Используются оригинальные собственные названия, графика и обои; чужие торговые марки не выдаются за продукты NOVA.

## Что сделано в исходниках

- KDE Plasma: схема BreezeLight (для новых пользователей), стандартное оконное управление, масштабирование средствами Plasma.
- NOVA Qt Tools: `air-light.qss` и `air-dark.qss`, переключение через NOVA Control (`~/.config/nova/theme`).
- Wallpaper: `/usr/share/wallpapers/NOVA/contents/images/1920x1080.png`. Скрипт задаёт фон один раз на первой сессии, далее пользовательский фон не переписывается.
- Вкладки Android Hub, NOVA Control и проверка ноутбука имеют прокручиваемую/масштабируемую компоновку Qt, но полное адаптивное проектирование для маленьких сенсорных дисплеев ещё не завершено.

## Сделано в 0.12

- **Plasma:** Look-and-Feel `org.nova.air.light.desktop` / `org.nova.air.dark.desktop` (Breeze-основа + цвета NOVA Air), цветовые схемы `NovaAirLight/Dark`, `/etc/xdg/kdeglobals` (Inter 10, тонкие рамки, двойной щелчок), SDDM и экран блокировки с обоями NOVA. Новые пользователи получают раскладку Windows-like из пакета оформления.
- **Режимы рабочего стола:** `nova-layout apply windows|dock|hybrid [--density compact|standard|touch]` через Plasma desktop scripting (без замены композитора). Резервная копия `~/.local/share/nova/layout-backups/` перед каждой сменой, `nova-layout restore`, `nova-layout reset-kde`.
- **Персонализация** (`nova-personalize`) по макету 02: тема светлая/тёмная/как в Plasma, 8 акцентов, режим и плотность, анимации, экран/тачпад/сенсор/экранная клавиатура, резервные копии и сброс.
- **Единый набор `nova_ui.py`** для всех 18 окон: токены (контраст ≥ 4.5:1), генерация QSS (файлы `air-*.qss` — сгенерированы), вписывание в экран, адаптивная навигация (< 820 px — выпадающий список), адаптивная сетка (1–3 колонки), диалоги с безопасной кнопкой по умолчанию, индикатор выполнения, фокус-рамки, Ctrl+Q / Ctrl+F, режим без анимаций.
- **Проверка адаптивности:** CI рендерит каждое окно на 1366×768, Full HD, 2K@125 %, 4K@200 % (светлая и тёмная тема) и проверяет, что окно и содержимое помещаются.

## Ещё предстоит

- Визуальная проверка режимов и тем в живой Plasma (скриншоты boot-test), доработка по результатам.
- Полная унификация браузера файлов, Центра уведомлений, входа в систему, центра быстрых настроек.
- Проверка на реальном сенсорном экране и HiDPI-ноутбуке (автоматически проверяются только размеры окон).
- Собственная QML-тема SDDM (сейчас — Breeze с обоями NOVA): только после проверки в VM, ошибка темы входа может закрыть доступ к системе.
- Слайды Calamares NOVA сделаны в 0.13 (ставятся при совпадении API со слайдами Debian).
- Проверка доступности со screen reader (Orca) и навигации только клавиатурой во всех окнах; контраст уже проверяется тестами.

`design/mockups/*.png` — это **концептуальные изображения**, не снимки запущенной сборки и не подтверждение реализации изображённых пунктов.
