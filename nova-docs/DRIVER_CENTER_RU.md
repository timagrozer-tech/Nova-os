# NOVA Driver Center — источники драйверов и установка

## Проверенные источники

1. **Debian APT** (обычный способ, работает по официальным репозиториям `deb.debian.org` / `security.debian.org`). Кандидат проверяется по метаданным `apt-cache policy`; пакеты скачиваются APT с проверкой целостности и подписи репозитория. Подписанные репозитории могут быть перенастроены администратором; поэтому NOVA запрещает автоматические установки, если происхождение кандидата не подтверждено.
2. **Сайты производителей**: NVIDIA `https://www.nvidia.com/en-us/drivers/`, AMD `https://www.amd.com/en/support.html`, Intel `https://www.intel.com/content/www/us/en/download-center/home.html`. Открываются браузером из NOVA Driver Center; их установщики не запускаются автоматически.
3. **LVFS/fwupd**: только запрос списка обновлений прошивок. Обновление BIOS/UEFI всегда отдельно от драйверов.

## Почему не автоустановка любого скачанного файла

Windows `.exe`-драйверы не становятся драйверами ядра Linux даже при Wine. Проприетарные Linux `.run` могут конфликтовать с версиями ядра и APT, особенно NVIDIA. Для безопасной автоматизации нужен подписанный пакет дистрибутива, совпадение архитектуры/ядра, проверка зависимостей и разрешение пользователя. NVIDIA 550 в Debian 13 имеет предупреждения безопасности; в этой версии NVIDIA остаётся ручным случаем.

## Как пользоваться в установленной NOVA OS

1. Откройте NOVA Control → Драйверы → NOVA Driver Center.
2. Выполните поиск оборудования; перейдите на вкладку «Скачать и установить».
3. Нажмите «Обновить каталог Debian» (потребуется интернет и подтверждение), затем дождитесь проверки.
4. Отметьте только необходимые пакеты с подтверждённым происхождением.
5. Нажмите «Скачать выбранные .deb» (не устанавливает) **или** «Автоустановка выбранных».
6. Подтвердите права администратора и после установки проверьте оборудование, перезагрузив систему при необходимости.

**Ограничения**: для установки в обычной системе нужны права администратора и подключение к интернету. В Live USB изменения заблокированы (избегаем иллюзии постоянной установки). Мастер не отключает Secure Boot, не прошивает BIOS и не удаляет драйверы сам. Инсталлятор продолжает быть экспериментальным; не менять разделы Windows до тестирования ISO.
