# NOVA OS 0.5 — Air + Android + Dual Boot + Migration (экспериментальный исходный проект)

**Состояние: исходники подготовлены, сборка ISO и тест установки не выполнены.**
Не заменяйте Windows 11 на этом этапе. Архив не содержит ISO и не является готовой новой ОС для повседневной работы.

## Сохранено из 0.4 — Windows не удаляется

- **NOVA Dual Boot:** графический советник с диагностикой UEFI/NTFS (только чтение), контрольным списком и запуском прежнего Hardware Check; в Calamares режим установки рядом с Windows, при необходимости — ручная разметка. Вариант стирания диска в Calamares **не отключён**.
- **Безопасный старт разметки:** `initialPartitioningChoice: none`; пакет `os-prober` и конфигурация GRUB для обнаружения Windows. Появление Windows в меню GRUB ещё требует реального теста.
- **NOVA Migration:** выборочные документы, фото, видео, музыка, загрузки, сохранения игр, закладки, пользовательская папка; экспорт каталога установленных Windows-программ для переустановки.
- Копии пишутся в отдельную папку Linux-пользователя. Исходный Windows-раздел только читается. Режим Live для копирования заблокирован во избежание потери данных после перезагрузки.
- **Не** переносит готовые Windows-программы, системный реестр, пароли, драйверы, лицензии и зашифрованные данные как работающие приложения.

Сначала прочитайте `nova-docs/DUAL_BOOT_RU.md` и `nova-docs/MIGRATION_RU.md`.

## Новое в 0.5 — звук, игры, телефон

- **NOVA Sound Studio:** девять созданных специально для проекта WAV-звуков; настройка зарядки по UPower, пользовательский каталог, импорт, редактор обрезки/затухания FFmpeg. Только зарядка автоматически подписана на системные события; прочие NOVA-события требуют вызова `nova-play-event`, остальные звуки KDE настраиваются отдельно.
- **NOVA Gaming:** Steam Big Picture по нажатию, проверка USB/Bluetooth-геймпадов, профили мощности, советы GameMode/MangoHUD, добровольная установка `steam-devices`. Steam устанавливается по выбору, не включён в образ.
- **NOVA Phone Hub:** USB и Wi-Fi через scrcpy/ADB, защищённое сопряжение по коду, KDE Connect для уведомлений/файлов, экспериментальный Android-виртуальный дисплей. Это НЕ настоящий Samsung DeX. `scrcpy` устанавливается по запросу из Debian Backports.
- Новые пункты NOVA Control и ярлыки KDE; сохраняются Android Hub, Dual Boot и NOVA Migration.
- **Проверено локально:** 25 из 25 Python-тестов, компиляция исходников, статическая проверка bash и файлов запуска; отдельно проверено создание OGG с эффектом fade из WAV через FFmpeg. **Не проверено:** загрузка ISO, работа GUI на KDE, звуки зарядки на ноутбуке, реальные геймпады или Android-смартфон.

См. `nova-docs/SOUND_EVENTS_RU.md`, `nova-docs/GAMING_RU.md`, `nova-docs/PHONE_RU.md`.

## Реализовано в этой версии исходников

- **База:** Debian 13 `trixie`, KDE Plasma 6, Calamares, Live ISO через `live-build`, ручной workflow GitHub Actions.
- **NOVA Air:** новая светлая и тёмная Qt-тема для NOVA Control, Defender, Uninstaller, Task Manager и Android Hub. Переключение темы из NOVA Control; светлая схема Breeze по умолчанию в новом профиле KDE.
- **Дизайн:** новый оригинальный пейзаж рабочего стола; шесть отдельностоящих утверждённых концепт-макетов (`design/mockups`). **Важно:** это изображения, а не готовая собственная оболочка. Пока используется стандартная панель KDE, а не отрисованный на макетах Dock.
- **Android Hub:** проверка Wayland/Waydroid, добровольная установка Waydroid из *официального Debian 13 Backports*, первичная настройка образа `VANILLA` или `GAPPS`, запуск, просмотр списка приложений и установка APK после подтверждения.
- **Google:** кнопки Gmail, Drive, Calendar открывают официальные веб-версии через системный браузер. Образ GAPPS не включён в ISO, скачивается на этапе первичной настройки по выбору пользователя. Google Play Protect может требовать сертификации. Не гарантируется работа Google Play, банковских приложений, DRM и ARM-only APK.
- **NOVA Preflight:** чтение состояния Wi-Fi/адаптеров/модулей/звука/GPU/дисков/UEFI; обязательный ручной чеклист и дополнительное подтверждение перед запуском Calamares из Live-сеанса. Сам код диагностики не пишет на диски.
- **NOVA Control:** раздел Android + существующие категории защиты, оптимизации, приватности, Windows-программ, поиска, удаления приложений, оформления, дисплея, сети и обновлений.
- **Windows-совместимость:** сохранены Wine, Bottles (устанавливается по запросу), Proton для игр через Steam (не устанавливается по умолчанию), виртуальная машина Windows при отдельной установке лицензированной ОС.
- **Office:** офисный пакет не предустановлен; для Microsoft 365 есть веб-доступ, для специфических настольных версий — Windows VM. **Совместимость со всеми версиями Microsoft Office или всеми Windows-программами НЕ гарантируется.**

## Ограничения

1. Нет собранного/протестированного ISO, нет подтверждённой загрузки с USB и проверки Secure Boot.
2. Не подтверждена работа NVIDIA, беспроводных контроллеров, микрофона, гибридной графики, веб-камеры и сна на вашем ноутбуке.
3. Параметры KDE дают широкий выбор оформления, но оконная оболочка не перерисована точно по концепт-макетам; виджетные панели и Dock еще требуют реализации.
4. Waydroid работает только в поддерживаемом сеансе Wayland и с подходящим ядром/драйверами. Для части Android APK понадобятся ARM-совместимость, проприетарные API и корректная сертификация.
5. ClamAV в Defender — проверка по требованию, а не полноценный Microsoft Defender и не гарантированная защита в реальном времени.
6. Проект не содержит установщик Microsoft Office, Google APK, ключи, пароли, драйверы NVIDIA с гарантией работы или исходные приложения Windows.

## Следующий реальный шаг — сборка и проверка

На Debian 13 amd64 с ~35+ ГБ свободного места и интернетом:

```bash
sudo bash tools/install-build-deps.sh
bash tools/validate-project.sh
sudo bash tools/build-iso.sh
```

Если успешно, ожидаемый результат: `output/NOVA-OS-0.5-amd64.iso` и `output/SHA256SUMS`. Это **ожидаемый результат команды**, не готовый файл архива.

Или вручную через GitHub Actions: загрузить исходники в репозиторий → Actions → `Build NOVA OS ISO (experimental)` → `Run workflow` → проверить статус и скачать артефакт.

Далее **сначала** проверить ISO в QEMU, записать на флешку через Rufus/Ventoy, запустить Live-систему, открыть NOVA Hardware Check и проверить устройство. Только после резервного копирования всех данных и успешного тестирования можно рассматривать установку рядом с Windows (без её удаления).

Читайте `BUILD_RU.md`, `CHECKLIST_RU.md`, `nova-docs/ANDROID_RU.md`, `nova-docs/DESIGN_RU.md`.

## Особые предупреждения Dual Boot

Перед переразметкой сделайте внешнюю резервную копию, сохраните ключ восстановления BitLocker, проверьте шифрование, отключите Fast Startup в Windows и сожмите Windows-раздел средствами «Управления дисками». В Calamares никогда не выбирайте «Стереть диск», если хотите сохранить Windows. Оба пункта меню GRUB должны быть испытаны после установки. **Сборка и тест установки 0.5 ещё не проведены.**
