# NOVA OS 0.4: установка РЯДОМ с Windows 11 (экспериментальная инструкция)

> **НЕ УСТАНАВЛИВАЙТЕ ДО ПОЛНОГО ТЕСТИРОВАНИЯ ISO И УСТАНОВЩИКА НА ВАШЕМ НОУТБУКЕ.**
> В исходном проекте Calamares умеет предлагать «Установить рядом», однако это НЕ обещание безопасности любой разметки. 
> Ошибочный выбор диска, сбой питания или ошибка файловой системы могут привести к потере Windows и данных.

## Что получим

При исправной настройке загрузчика после установки в меню GRUB будут пункты NOVA OS и Windows Boot Manager. Выбор системы делается при включении, без удаления Windows. Не путайте с одновременным запуском двух ОС.

## Перед загрузкой флешки — именно в Windows 11

1. Скопируйте документы, фото и критические данные на **внешний накопитель**; проверьте, что они открываются. Сохраните образ восстановления и установочную флешку Windows.
2. Откройте Windows **Параметры → Конфиденциальность и безопасность → Шифрование устройства** и/или **Управление BitLocker**. Запишите ключ восстановления BitLocker в надёжном месте ВНЕ ноутбука. Изменение разделов при шифровании возможно только с учётом состояния BitLocker; если сомневаетесь — сперва обратитесь к документации производителя. NOVA не будет пытаться обходить шифрование.
3. Отключите Windows **Быстрый запуск (Fast Startup)** и гибернацию штатно. Это существенно для безопасного доступа к NTFS с Linux; после Windows Update проверьте снова.
4. Нажмите `Win+X` → **Управление дисками**, выберите системный NTFS-том, **Сжать том**. Освободите **около 100 ГБ или более** (для Windows-программ, Android и игр лучше 150–250 ГБ). Это рекомендация планирования, а не минимальное требование Calamares. Оставьте область **Нераспределена**: не форматируйте её в NTFS.
5. Убедитесь, что ноутбук загружается в UEFI и установленный Windows Boot Manager виден в настройках загрузки. Не меняйте режим загрузки Windows на Legacy.
6. Подключите ноутбук к зарядке.

## В Live NOVA OS с флешки

1. Проверьте сеть, Wi-Fi, звук, экран, клавиатуру, тачпад, GPU, сон.
2. Откройте **NOVA Dual Boot** — это только диагностика; разделы и EFI он не изменяет.
3. Прочтите контрольный список и откройте **NOVA Hardware Check**.
4. После проверки запустите Calamares. В разметке выбирайте **Install Alongside / Установить рядом** только если он показывает правильный Windows-раздел и итоговый план сохраняет Windows. Если нет — отмените установку.
5. Если подготовили нераспределённое место из Windows, может потребоваться **ручная разметка**: создайте новый раздел `ext4` с точкой монтирования `/` ТОЛЬКО в свободном пространстве. Для UEFI укажите существующий EFI System Partition как `/boot/efi` **БЕЗ ФОРМАТИРОВАНИЯ**. НИКОГДА не форматируйте/удаляйте Windows NTFS, EFI, MSR или Recovery-разделы.
6. В финальном просмотре действий проверьте **каждый диск и каждую операцию**. Если видите «форматировать Windows», «удалить раздел восстановления» или «стереть диск» — **Отмена**.
7. После первой перезагрузки проверьте загрузку и Windows, и NOVA OS. Если Windows в GRUB не появилась, НЕ стирайте Windows: откройте UEFI Boot Menu и проверьте Windows Boot Manager. Затем можно диагностировать `os-prober` и `update-grub` в NOVA.

## Что уже сделано в исходниках

- `NOVA Dual Boot` — read-only отчёт о разделах и UEFI с ручным чеклистом.
- Calamares: `initialPartitioningChoice: none` (никакой вариант не выбран автоматически). **Опция «Стереть диск» по-прежнему доступна**; полностью исключить её этим файлом нельзя.
- Установлено `os-prober`, конфигурация `GRUB_DISABLE_OS_PROBER=false` в `/etc/default/grub.d/90-nova-dualboot.cfg`.
- Утилита NOVA Migration для переносимых пользовательских данных уже после установки.
- `tools/windows/NOVA-Windows-Export.ps1` — необязательный помощник для учёта приложений и проверки некоторых параметров Windows. Он не изменяет разделы или BitLocker.

## Чего пока не доказано

Не проверены ISO, установка, UEFI/Secure Boot конкретного ноутбука, распознавание Windows, гарантированное появление Windows Boot Manager в GRUB и сохранность обеих ОС. Это **исходный проект, не готовый проверенный установочный продукт**.

Основано на официальных инструкциях Calamares, Debian 13 (Windows Dual Boot / Fast Startup / BitLocker) и практиках безопасного управления разделами.
