# NOVA Welcome / Health — руководство

При первом обычном запуске KDE автоматически открывается NOVA Welcome. Ничего не
устанавливается и не передаётся в Интернет. Можно пройти шесть экранов,
открывая нужные инструменты, либо закрыть окно и пройти позже через NOVA Control.
Только кнопка «Готово» отмечает настройку завершённой.

NOVA Health находится в меню приложений и NOVA Control. Нажмите «Проверить снова»
для чтения состояния системы. Признак «информация» означает, что команда
вернула ответ, **не** что компонент протестирован или исправен.

При сохранении отчёта выберите уникальное имя: существующий файл не
перезаписывается. Скрытие сетевых адресов и домашнего каталога работает в
базовых случаях, но перед отправкой проверьте содержимое вручную.

Вариант «Подключить NVidia» не выполняется автоматически: наличие RTX 4050
нужно проверять на самом ноутбуке, с его конкретным драйвером и Secure Boot.

## Проверка будущего ISO, когда сборка будет готова

- `bash tools/verify-iso.sh` — сравнивает SHA-256 и печатает сведения о загрузке ISO.
- `bash tools/test-qemu.sh` — BIOS-симуляция без подключения дисков ноутбука.
- `bash tools/test-qemu-uefi.sh` — UEFI-симуляция через OVMF с временными переменными прошивки.

Эти проверки не форматируют диск, но и не гарантируют сохранность данных
при последующей установке. Запускать только после успешной сборки образа.
