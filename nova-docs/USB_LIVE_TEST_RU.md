# Проверка NOVA OS с USB-флешки, не трогая Windows 11

Цель: загрузить NOVA OS **в режиме Live** (система работает с флешки и в памяти), проверить оборудование и ничего не менять на внутреннем диске. Установку рядом с Windows делайте только после успешной проверки и резервной копии (план 0.13).

## Что нужно

- ISO из GitHub Actions (артефакт `NOVA-OS-0.12-ISO`) и файл `SHA256SUMS`.
- Флешка от 8 ГБ (всё на ней будет стёрто при записи).
- Компьютер с Windows для записи (или Android-приложение для записи образов — см. ниже).

## 1. Проверьте контрольную сумму

В PowerShell: `Get-FileHash .\NOVA-OS-0.12-amd64.iso -Algorithm SHA256` — значение должно совпасть с `SHA256SUMS`. На Android подойдёт любой файловый менеджер/утилита с SHA-256.

## 2. Запишите флешку — вариант A: Ventoy (несколько ISO на одной флешке)

1. Скачайте Ventoy с официального сайта ventoy.net, запустите `Ventoy2Disk.exe`, выберите **флешку** (не диск компьютера!), нажмите Install. Флешка будет отформатирована (по умолчанию exFAT — подходит для ISO больше 4 ГБ).
2. Просто скопируйте `NOVA-OS-0.12-amd64.iso` на флешку как обычный файл.
3. При включённом Secure Boot при первой загрузке Ventoy появится синий экран MOK: выберите *Enroll key from disk* → `ENROLL_THIS_KEY_IN_MOKMANAGER.cer` → подтвердите → перезагрузка. Это добавляет ключ Ventoy, Windows это не затрагивает.
4. Если NOVA не стартует через Ventoy в обычном режиме, в меню Ventoy выберите режим GRUB2 для этого ISO либо используйте вариант B.

## 2. Запишите флешку — вариант B: Rufus (самый надёжный для этого ISO)

1. Rufus с rufus.ie → Устройство: ваша флешка → Выбрать ISO.
2. Схема разделов: **GPT** (целевая система UEFI). Нажмите «Старт».
3. На вопрос о режиме записи выберите **«Записать в режиме DD-образа»** — ISO NOVA гибридный, DD-копия совпадает с проверенным образом побайтно.

На Android без ПК: приложения вроде *EtchDroid* записывают ISO на флешку через OTG-переходник в режиме, аналогичном DD.

## 3. Подготовьте Windows 11 (ничего не удаляя)

- **BitLocker:** сохраните ключ восстановления (Параметры → Конфиденциальность и защита → Шифрование устройства, или aka.ms/myrecoverykey). Смена порядка загрузки иногда вызывает запрос ключа — без него можно потерять доступ к Windows.
- **Быстрый запуск:** отключите (Панель управления → Электропитание → Действия кнопок питания → снять «Включить быстрый запуск»). Иначе Windows оставляет NTFS в «гибернированном» состоянии.
- **Режим загрузки:** `Win+R` → `msinfo32` → «Режим BIOS» должен быть **UEFI**.
- Secure Boot можно **не отключать**: NOVA использует подписанные загрузчики Debian.

## 4. Загрузитесь с флешки

- Самый простой путь: в Windows удерживайте **Shift** и нажмите «Перезагрузка» → *Использовать устройство* → ваша флешка.
- Или клавиша меню загрузки при включении (часто F12, F11, F9, Esc — зависит от производителя).
- В меню GRUB выберите первый пункт (Live). Вход в систему произойдёт автоматически (пользователь `user`, пароль `live`).
- Раскладка: **Alt+Shift** переключает EN/RU.

## 5. Что проверить в Live-сессии

1. Меню приложений → **«NOVA — самопроверка системы»**. Сохраните отчёт (кнопка в окне терминала не нужна — выделите текст или запустите `nova-selftest --output ~/report.txt`, затем скопируйте на флешку/в облако).
2. Подключите Wi-Fi, включите видео со звуком, проверьте микрофон, Bluetooth-наушники.
3. Тачпад: прокрутка двумя пальцами, жесты; при необходимости «касание = щелчок» в Персонализации → Тачпад.
4. Экран: Персонализация → «Экран и масштабирование» (100–200 %). Внешний монитор.
5. Видеокарта: в отчёте самопроверки видно, на каком драйвере работают GPU. Для гибридной AMD/Intel + NVIDIA в Live нормально работать на встроенной графике; проприетарный NVIDIA ставится только **после** установки через NOVA Driver Center.
6. Оформление: **NOVA — персонализация** → светлая/тёмная тема, режимы Windows-like / Dock-like / Hybrid, «Вернуть KDE Plasma по умолчанию».

Если экран чёрный: в меню GRUB нажмите `e`, допишите `nomodeset` в строку `linux …`, затем F10. Сообщите модель ноутбука и видеокарты.

## 6. Чего НЕ делать на этом этапе

- Не запускайте «Установить NOVA OS» на реальном диске, пока нет резервной копии и пока сценарий рядом с Windows не проверен в VM (0.13).
- Не меняйте разделы в KDE Partition Manager.
- Не отключайте Secure Boot, BitLocker, брандмауэр «ради скорости».

Результаты занесите в `nova-docs/TEST_MATRIX_RU.md` (модель ноутбука, дата, что работает/не работает).
