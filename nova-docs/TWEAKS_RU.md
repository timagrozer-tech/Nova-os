# NOVA OS 0.2 — Настройки, функционал и безопасность

## NOVA Control (12 вкладок)

1. Обзор: характеристики устройства, доступ к инструментам.
2. Конфиденциальность: Flatseal, разрешения, переключение индекса Baloo, Wi-Fi/Bluetooth.
3. NOVA Defender: AppArmor, UFW, ClamAV, обновления базы сигнатур (через официальный сервис).
4. NOVA Optimizer: power-profiles-daemon, диагностические операции, кэш APT, автозапуск.
5. NOVA Uninstaller: APT + Flatpak по подтверждению, с защитой зависимостей, Bottles.
6. Диспетчер задач: процессы, CPU/RAM, диски, сетевой трафик, остановка собственного процесса.
7. Быстрый поиск: KRunner, Baloo, включение/выключение индекса.
8. Windows-программы: Wine, Bottles, Microsoft 365 веб, виртуальная машина для Windows.
9. Персонализация: глобальная тема, цвет, иконки, курсоры, шрифты, оформление окон, эффекты, виртуальные столы, горячие клавиши, автозагрузка.
10. Дисплей и звук: разрешение, масштабирование, мониторы, PipeWire и Bluetooth.
11. Сеть и устройства: NetworkManager, диагностика драйверов, fwupd.
12. Обновления и копии: Discover и Timeshift.

## Не включаем без доказательств пользы

* Отключение AppArmor, микрокода, автоматических обновлений и проверок безопасности.
* Бездумное отключение журналов, аудио-, энергосберегающих и сетевых служб.
* Глобальную очистку домашнего каталога и «остатков приложений» через угадывание имён.
* «RAM оптимизаторы», принудительное переписывание sysctl, random kernel flags.
* Автоматическую установку NVIDIA без проверки видеокарты и Secure Boot.

## Следующие этапы

Проверка сборки ISO и GUI в реальном Debian, установка в QEMU с виртуальным диском; hardware matrix для NVIDIA/Realtek/MediaTek/Intel Wi-Fi, тачпад, веб-камера, сон, гибридная графика; затем устойчивые откаты изменений, графическое управление Wine-бутылками, дополнительные настройки защиты и оформление согласно макетам.
