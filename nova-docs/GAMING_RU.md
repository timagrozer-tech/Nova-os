# NOVA Gaming — игры и контроллеры

- Собственное окно `nova-gaming`: ручной запуск `steam -bigpicture`; проверка USB/Bluetooth-контроллеров по `/proc/bus/input/devices`; советы по настройке Steam Input, GameMode/MangoHud, профили `powerprofilesctl`.
- База — Debian 13 + KDE. Steam **не включён по умолчанию**: пользователь устанавливает отдельно через официальные пакеты/магазин; логин Steam не обслуживается NOVA.
- Пакет `steam-devices` можно поставить отдельно по подтверждению через `pkexec nova-gaming-admin install-gamepad-rules`. Это добавляет udev-права для устройств Sony, Xbox и Steam; на общем ноутбуке эти разрешения могут быть нежелательны.
- DualShock 4 и DualSense поддерживаются Steam Input при наличии исправных Linux Bluetooth/USB-драйверов и прав. Специальные функции вроде адаптивных триггеров зависят от игры, драйвера, соединения и Steam.
- GameMode и MangoHUD есть в списке системных пакетов. В Steam для конкретных игр можно использовать `gamemoderun %command%` или `mangohud %command%`.
- Не включаем автоматически разгон, выключение защиты, изменение лимитов мощности GPU и не запускаем игры без выбора пользователя.
- Полноценная поддержка всех игр Steam/Windows и античитов невозможна; проверять каждую игру отдельно.

Тестирование DualShock/DualSense в реальном ноутбуке не проводилось.

## Новое в 0.6: тест кнопок

В NOVA Gaming откройте «Тест кнопок и стиков». Программа ищет `/dev/input/jsN`
и показывает события нажатия кнопок и изменения осей **только для чтения**.
Запуск с sudo не нужен. Если `jsN` не существует, драйвер ядра/адаптер или
модуль `joydev` может отсутствовать; диагностируйте через Steam Input и Linux.
Особые возможности DualSense (триггеры, тактильная отдача) зависят от игры.
