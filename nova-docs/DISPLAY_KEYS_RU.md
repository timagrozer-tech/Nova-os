# Дисплеи, горячие клавиши и Game Bar (NOVA OS 0.12)

## NOVA — дисплеи (`nova-display`, Win+Shift+P)

- Для каждого монитора: разрешение, **частота обновления (Гц)** (список реальных режимов монитора, отметка «максимум»), масштаб 100–300 %, поворот, адаптивная частота (VRR/FreeSync), включение и выбор основного монитора.
- **Второй монитор как Win+P:** «Только экран компьютера», «Повторяющийся», «Расширить» (справа/слева/сверху/снизу), «Только второй экран». В Plasma также работает Win+P.
- **Защита от чёрного экрана:** после применения 15 секунд на подтверждение, иначе прежние параметры возвращаются сами.
- **Профили мониторов** («Дом», «Работа», «Проектор»): сохранить расстановку и применить одним нажатием.
- **Яркость внешнего монитора** по DDC/CI (`ddcutil`, модуль `i2c-dev`); в меню монитора должна быть включена DDC/CI.
- **Экономия батареи:** на батарее встроенный экран переходит на ~60 Гц, от сети — на максимум (по умолчанию выключено).
- Команды: `nova-display list`, `nova-display max-hz`, `nova-display hz HDMI-A-1 144`, `nova-display project extend --side left`, `nova-display profile save Дом`, `nova-display battery-hz on`.

Под капотом — `kscreen-doctor` (KDE Plasma), без root. Имена мониторов и режимы проверяются, команды shell не используются.

## Горячие клавиши как в Windows (`nova-hotkeys`)

Включены по умолчанию для новых пользователей (`/etc/xdg/kglobalshortcutsrc`). Для существующего пользователя: «Сочетания как в Windows» в окне или `nova-hotkeys apply`. Возврат: `nova-hotkeys reset-kde`. Перед изменением сохраняется копия `~/.config/kglobalshortcutsrc`.

| Клавиши | Действие |
|---|---|
| Win+↑ / Win+↓ | развернуть / свернуть окно (в KDE было «прикрепить к верху/низу») |
| Win+Tab | представление задач (Обзор) |
| Win+Shift+S | снимок области экрана |
| Win+Пробел | смена раскладки (также Alt+Shift) |
| Ctrl+Shift+Esc | диспетчер задач NOVA |
| Win+I | NOVA Control (параметры) |
| Win+R, Win+S | выполнить / поиск (KRunner) |
| Win+G | NOVA Game Bar |
| Win+Pause | сведения о системе |
| Win+Shift+P | NOVA — дисплеи |

Уже есть в Plasma и не менялись: Win, Win+E, Win+D, Win+L, Win+V, Win+., Win+P, Win+←/→, Win+Shift+←/→, Win+Ctrl+←/→, Win+T, Alt+Tab, Alt+F4, Print.

## Мультимедийные клавиши

- Громкость меняется с **шагом 2 %**, как в Windows (`/etc/xdg/plasmaparc`; изменить: `nova-hotkeys volume-step 5`). Плюс экранный индикатор, «без звука», выключение микрофона, Play/Pause/Next/Prev для любого плеера и браузера, яркость, режим полёта — штатно в Plasma.
- Клавиши «Калькулятор», «Мой компьютер/Проводник», «Домашняя страница», «Почта», «Инструменты» открывают kcalc, Dolphin, браузер, почту (клиент или веб-почта из `~/.config/nova/webmail`) и NOVA Control.
- **Проверка клавиш** в окне горячих клавиш показывает, как система видит нажатую кнопку (имя, скан-код). Это помогает с нестандартными кнопками ноутбука.

## NOVA Game Bar (Win+G)

Окно поверх игры: загрузка CPU, память, температура процессора, батарея; профиль питания (с предупреждением для «Максимум»); громкость и микрофон; снимок области и запись экрана (Spectacle); состояние GameMode и MangoHud; Steam Big Picture. Esc скрывает. Никакого разгона и отключения защит.

## Сторонние проекты с GitHub

В ISO попадают только пакеты из подписанного архива Debian. Через Debian подключены проекты, которые разрабатываются на GitHub: **Papirus** (значки, переключаются в Персонализации), **MangoHud**, **GameMode**, **ddcutil**; по запросу пользователя — **scrcpy**, **Waydroid** (Debian backports), **Bottles**, **Flatseal** (Flathub). Скачивание кода из случайных репозиториев при сборке не используется: его нельзя проверить подписью.

## Не проверено

Работа на реальных мониторах (частоты, DDC/CI, VRR), фактические имена мультимедийных клавиш на конкретном ноутбуке и вид Game Bar в живой сессии проверяются при первом запуске на Live USB и в скриншотах CI.
